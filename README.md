## 👨‍💻 About Me

I'm a developer focused on **Artificial Intelligence Engineering**, exploring how Large Language Models and Generative AI can be used to build useful, reliable, and intelligent applications.

My interests include building LLM-powered systems, designing retrieval pipelines, experimenting with model adaptation, and developing AI agents that interact with tools and external data.

- 🧠 Exploring **LLMs and Generative AI**
- 🔎 Building and studying **Retrieval-Augmented Generation (RAG)** systems
- 🤖 Learning to develop **AI agents and tool-calling workflows**
- ⚙️ Exploring **LoRA, QLoRA, and parameter-efficient fine-tuning**
- 🐍 Developing projects with Python
- 📚 Continuously learning through experimentation and hands-on projects

> My goal is to turn AI concepts into practical engineering solutions.
